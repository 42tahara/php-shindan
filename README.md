# PHP 事前診断ファイル

自分のサイトのサーバーに、PHP ファイルを 1 つ置いて、ブラウザで開くだけで、PHP と WordPress の「いまの状況」を画面に出します。
PHP の重大な脆弱性（CVE-2026-109618 / CVE-2026-109619）に、自分のサイトが関係するかを、まず確かめるために作りました。

> **これは目安を出すツールです。脆弱性の有無の断定も、安全の保証もしません。**

## 何がわかるか

- PHP の版、動かし方（Apache の mod_php か、FPM かなど）、関連する ini 設定
- WordPress の版、プラグイン・mu-plugins・テーマの名前と版（インストール済みのもの。有効かどうかは判定しません）
- 判定の目安: PHP の版が、php.net の修正版（2026-10-21 公開）以降かどうか

## 何をしないか

このスクリプト自身は、次のことをしません。

- 外部への通信（結果は画面に出るだけで、どこにも送られません）
- データベースへの接続、`wp-config.php` の読み取り
- このファイル自身以外の、ファイルの書き換え・削除・作成

読み取るのは、このファイルを置いた場所と、その親（最大 3 階層）で見つかった WordPress の中だけです。
プラグイン・テーマは、各ファイルの先頭 8KB（ヘッダ部分）から、名前・版・親テーマだけを取り出します。
シンボリックリンクの先が WordPress の外、または `wp-config.php` のときは、読みません。

## 使い方

1. [`shindan.php`](shindan.php) をダウンロードします。
2. テキストエディタで開き、先頭近くの 2 行を書き換えます。
   - `$TOKEN`: 16 文字以上の、推測されにくい文字列にします（例: ターミナルで `openssl rand -hex 16`）。
   - `$EXPIRES`: 数日後の日時にします（例: `'2026-11-05 18:00'`）。期限を過ぎると、404 になります。
3. WordPress と同じ（または親の）ディレクトリに、FTP などで置きます。
4. ブラウザで `https://あなたのサイト/shindan.php?k=<$TOKEN の値>` を開き、「診断を実行する」を押します。
   ボタンを押すまで、何も実行されず、削除もされません（リンクの先読み対策です）。
5. 結果が表示されます。表示と同時に、ファイルは自分で削除されます。

`$TOKEN` を書き換える前の状態（`__TOKEN__` のまま）では、404 が返るだけです。

### 削除について

- 削除できないときは、中身を「404 を返すだけ」に置き換えます。画面に警告が出ます。
- それもできないときは、画面に警告が出ます。**FTP などで、すぐ手動で削除してください。**
- 合言葉と有効期限が切れれば、残っていても 404 になります。ただし、期限までは結果を再表示できます。
- 結果の画面に `self_cleanup=deleted` と出ていれば、削除済みです。

## 注意

- **合言葉は URL に含まれます。** アクセスログやブラウザの履歴に残ります。URL は、他の人に見せないでください。
- **結果は、貼る場所を選んでください。** サイトの構成を示す情報です。公開の掲示板やチャットには、貼らないでください。
- 共用レンタルサーバーで、置いても動かない場合があります（サーバー側が PHP の実行を制限している場合など）。
- 標準と違う構成（`WP_CONTENT_DIR` を変えた構成、`wordpress` が子ディレクトリにある構成）では、プラグインやテーマが見つかりません。
  このときは「見つからない」と出るだけで、「無い」という意味ではありません。
- **版番号だけでは判定できないことがあります。** Linux ディストリビューションやホスティング会社は、版番号を上げずに修正を取り込むことがあります。

## 動作確認

| PHP | 動かし方 | 結果 |
|---|---|---|
| 5.6.40 | Apache 2.4 + mod_php（Docker 公式イメージ） | 通過 |
| 7.4.33 | Apache 2.4 + mod_php（Docker 公式イメージ） | 通過 |
| 8.1.34 | Apache 2.4 + mod_php（Docker 公式イメージ） | 通過 |
| 8.4.20 | PHP 組み込みサーバー | 通過（関数の無効化など、異常系も確認） |

PHP 5.2〜5.5 は、実機で確認できていません（構文は 5.2 を意識して書いています）。

## 判定基準の更新

判定の基準日は 2026-10-22 です。`shindan.php` の `$fixed`（系統ごとの最低修正版）と `$BASIS_DATE` を直してください。
修正版の情報は、[php.net](https://www.php.net/) の告知を確認してください。PHP 8.2 は 2026-12-31 でセキュリティサポートが終わります。
